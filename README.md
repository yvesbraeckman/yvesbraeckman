### Featured Project: Smart Parcel Wall
One of my most recent projects is the **Smart Parcel Wall**, a seamless integration of hardware and cloud technology:
*   **Edge Computing:** Powered by a Raspberry Pi acting as the edge node.
*   **Full-Stack Integration:** A robust cloud backend that communicates directly with the hardware.
*   **Digital Twin:** A custom-built dashboard to monitor and manage the status and data of the wall in real-time.
